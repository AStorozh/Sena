# Сайт-презентация Сены

Чистые HTML, CSS и JS без сборщика и библиотек.

## Запуск и проверка

```
python3 site/serve.py        # http://127.0.0.1:8790/, файлы без кэша
python3 site/shot.py 3 10    # снимки первого экрана в /tmp/sena-site/ на 3-й и 10-й секунде: Mac (Retina), широкий, планшет, телефон
tools/pack.sh                # файлы раздела «Скачать» в dist/ (в git не попадают): код последнего коммита и sena.apk, если он собран
```

Перед показом смотреть снимки всех размеров. Retina проверять обязательно: одна ошибка была видна только при плотности 2.

## Где что лежит

```
index.html          разметка; у файлов метка ?v=N — поднять у всех после правки, чтобы браузер взял свежие
fonts/              шрифты сайта (Onest, IBM Plex Mono; лицензия SIL OFL) — лежат рядом, Google не нужен
css/base.css        цвета и шрифты (:root), меню-капсула, кнопки — общее для всего сайта
css/build.css       сборка курсорами: курсоры, рамки с размером, направляющие, счётчик слоёв
css/world.css       поле точек, персонажи и их подписи, огромные слова (.giant), подсказка «можно хватать»
css/hero.css        только первый экран
css/sections.css    разделы ниже первого экрана
js/agents.js        единый список агентов (код, роль, цвет) и общие Sena.wait, Sena.reduced
js/lang.js          русский и английский: словарь ru → en, Sena.t(строка), кнопка EN/RU
js/characters.js    рисунок персонажа: тело, глаза, эмоции, мысли (перенос mac/Sources/Views/Character.swift)
js/build.js         страница собирает себя сама: Sena.build.run(элементы), Sena.build.watch()
js/world.js         площадка агентов: физика, опоры, поле точек, задачи — Sena.World({...})
js/ui.js            мелочи: магнитные кнопки (.magnet)
js/hero.js          первый экран: сценки с просьбами, капсула «что делает команда», запуск
js/sections.js      мини-агенты (canvas.mini), выбор лиц, счётчики, площадка автора
js/viz.js           живые картинки разделов: демо на Mac и телефоне, орбита команды, графики, дорожка атак, граф памяти,
                    маршрутизатор дом/облако, граф git, экраны из JSON, прогон CI — функция scene(id, ...) на каждый раздел
js/paper.js         фон из точек на весь сайт, совпадает с сеткой первого экрана
```

Порядок скриптов важен: сначала `agents.js`, потом движки, потом разделы.

## Как добавить раздел

1. Разметка в `index.html` после первого экрана: `<section data-build-section>`.
2. Всё, что должно строиться курсорами, помечается `data-build`:
   - `type` — курсор растягивает рамку текста и печатает его по буквам;
   - `box` — рамка закрашивает фон элемента (кнопка, карточка), потом печатается текст внутри;
   - `carry` — курсор приносит элемент сверху и ставит на место (буквы огромных слов).
   Элементы строятся в порядке разметки. Раздел соберётся сам, когда на четверть покажется на экране.
   Свою анимацию раздел начинает по событию `built` (раздел уже собран): `once("id", fn)` в `sections.js`.
   Живой мини-агент: `<canvas class="mini" data-agent="ag_web" data-thought="search">`, его лицо — `canvas.face`.
3. Стили раздела — в `css/sections.css` (или свой файл, если раздел большой); цвета и шрифты только из `:root` в `base.css`.
4. Если в разделе нужны живые персонажи — свой `Sena.World` с полем (`canvas.field`) и сценой (`div.stage`), как в `hero.js`.
   Огромное слово для опоры — `<span class="giant" data-text="Слово">`.
5. Логика раздела — функция в `js/sections.js` (большой раздел — свой файл в конце списка скриптов).

## Правила

- Светлая тема, фон из точек на всём сайте. Бегущих строк нет нигде.
- Никаких одинаковых карточек-блоков: у раздела своя живая картинка — схема, график, интерфейс.
- Цвета агентов — только из `js/agents.js`.
- Каждому `canvas` персонажа задаётся размер в CSS: иначе на Retina он растёт сам от себя.
- Ожидание шрифтов не дольше 3 с: страница не должна стоять пустой, пока шрифты грузятся.
- Комментарии в коде — по-английски, тексты на странице — по-русски, а английский перевод каждой новой строки — в словарь `js/lang.js`.
  Строки, которые показывают скрипты, проходят через `Sena.t(...)`. Проверка: на английской странице не должно остаться кириллицы.
