# Замер моделей

Каждое дело Сены, где работает облачная модель, прогоняется на нескольких моделях Claude и OpenAI настоящим кодом Сены:
меняется только модель. Итог — таблица «качество, цена, скорость» по каждому делу. Первый замер (25.10.2026):
цифры — в `summary-2026-10-25.json`, выводы — в `verdict.json`.

Замер тратит настоящие деньги (полный прогон восьми моделей стоил около 26 $). Данные не трогает: прогоны идут на копии памяти
и настроек в `world/` (она не попадает в git). Копия, прогоны и результаты закрыты от других пользователей Mac, как `data/`:
в них те же люди и переписка. Gemini (голос, слух) зовётся через `sena/google/media.py`, расход пишет `sena/core/costs.py`.

## Что меряется

- `bench_brain.py` — мозг и голосовые команды на экзамене ума (sena/exam).
- `bench_web.py` — агент браузера на тестовом магазине `shopsite.py`; `hard` — трудные задачи.
- `bench_mac.py` — агент компьютера в песочнице macOS (пишет только в папку задачи, дома и сети не видит); `hard` — трудные задачи.
- `bench_judge.py` — судья на законченных задачах с известной правдой.
- `bench_narrow.py` — мелкие дела: время в правиле, выбор рецепта, сводка переписки.
- `bench_local.py` — те же мелкие дела на домашней модели (бесплатно): дотягивает ли она до облачной.
- `bench_voice.py` — распознавание и озвучка (OpenAI, Gemini, домашние модели).

## Как запустить

```
cd tools/model_bench
python3 world.py                                   # копия памяти и настроек для прогонов
SENA_DATA=$PWD/runs/keeper python3 keeper.py &     # один сервер домашних моделей на все прогоны (сначала: python3 -c "import world; world.copy(world.HERE / 'runs' / 'keeper')")
./run_matrix.sh claude-opus-5-5,gpt-6.1-sol main   # все дела для перечисленных моделей
python3 report.py                                  # сводка в results/summary.json
python3 page.py                                    # страница report.html (выводы берёт из verdict.json)
python3 journal.py --write                         # расход замера — в настоящий журнал расходов
```

Отдельное дело для нескольких моделей: `python3 launch.py <brain|web|mac|judge|narrow> <метка> <модель,модель> [аргументы]`.
