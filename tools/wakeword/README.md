# Обучение детектора имени «Сена»

Это разовый инструмент разработчика, при работе Сены он не нужен. Результат — файл `models/sena.onnx`,
который слушает звук телефона и отвечает «прозвучало ли имя» (второй способ рядом с whisper, см. `sena/phone/speech.py`).

Порядок:
1. `generate.py` — синтезирует примеры: имя в разных формах (Сена, Сенка, Hey Sena...) и похожие слова, которые имя не означают (сенат, цена, Лена...).
   Голоса: Piper (русские и английские); часть русских примеров дополнительно озвучена голосами OpenAI TTS.
2. `train.py [шагов]` — свой цикл обучения: мягкое зашумление (`augment.py`), отбор модели по полноте при не более 1 ложного срабатывания в час.
   Результат — `sena.onnx` рядом со скриптом; скопировать в `models/`.
3. `evaluate.py путь/к/sena.onnx` — проверка на голосе macOS (`say`), которого в обучении не было.

Чего нет в репозитории и надо скачать самому: `piper-sample-generator/`, `voices/`, фоновые шумы и `rirs/` в `data/`.
Почему именно так (и три неудачные попытки до этого) описано в истории решений (раздел «Детектор имени»); она ведётся
в приватной версии и в публичный репозиторий не входит. Готовая модель `models/sena.onnx` тоже не публикуется: её обучают
этим кодом.
