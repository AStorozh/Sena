# Приложение Сены для Mac

Родное приложение на SwiftUI для macOS 14+, без Xcode-проекта: `./build.sh` собирает `swiftc` → `Sena.app`.
Данные берёт только у сервера Сены (`sena/phone/desk.py`, `panels.py`); своей логики данных не имеет. Если ядро
выключено, приложение само поднимает экран без ядра (`python -m sena.phone`), а Сену включает кнопка «Запустить Сену».
Правила оформления — в CLAUDE.md проекта; какие поля приложение читает у сервера, проверяет `tests/test_mac.py`,
оформление — `tests/test_mac_style.py`.

## Файлы

- `Sources/App.swift` — окно, меню, значок в строке меню.
- `Sources/API.swift` — запросы к `/desk/api`, экран без ядра.
- `Sources/Model.swift` — состояние, опрос, действия, уведомления, разделы и подразделы.
- `Sources/Style.swift` — единственное место оформления: шрифт, размеры текста и значков, отступы, скругление
  (`Style.Radius.all`), размеры элементов, цвета, движение (`Style.Motion`), графики (`Style.Chart`).
- `Sources/Ears.swift` — живой голос с микрофона Mac: поток на сервер `voice.py`, её голос играет сразу; все вызовы
  звукового движка идут через одну очередь (смена наушников во время речи не роняет приложение).
- `Sources/Recorder.swift` — голосовые сообщения; пока идёт запись, живой голос не слушает.
- `Sources/Leaf.swift` — лист Сены (`LeafMark`): значок и живая анимация загрузки.
- `Sources/Views/` — экраны разделов и общие части:
  - `Components.swift` — блоки экрана: `Block`, `Stat`, `Bar`, `Columns`, `AdaptiveRow`, `.row`, кнопка `SenaButton`, метка `Tag`;
  - `Graphs.swift` — `BarGraph`, `AreaGraph`, `Donut`;
  - `Motion.swift` — движение: значки (`Glyph` и таблица `Glyphs`), числа перекатом (`.rolling`), наведение, загрузка;
  - `Widgets.swift` — мини-панель (⌘⇧M); `NotchPanel.swift` — полка у выреза с чатом;
  - `Switch.swift` — выключатель `SenaSwitch`; `Toast.swift` — уведомление `ToastBubble`.

## Разделы

Девять разделов меню (`Screen.allCases`), подразделы — в шапке (`Screen.tabs`):
Чат (Переписка | Файлы), Задачи (Список | Схема), Правила, Сена ведёт (панели, которые описывает сервер),
Память (Факты | Люди | Заметки | Навыки), Секреты, Интеграции, Журнал (Расходы | События | Лог),
Настройки (Поведение | Система | Саморазвитие).

Раздел называется тем, что в нём лежит целиком; вкладка не повторяет имя раздела. Подписи — на «ты», у управления
заглавная буква. Период данных везде один — даты «с … по …» в шапке (`PeriodPicker`).
Действия раздела — через `.actions { }` в шапку.

## Язык

Русский и английский по языку системы (`isEnglish` в Model.swift). Каждая видимая строка обёрнута в `L("…")`,
перевод — `Resources/{ru,en}.lproj/Localizable.strings`; название и вопросы системы — `InfoPlist.strings`.
Свои компоненты (`Block`, `Tag`) берут обычный `String`, поэтому автоматический перевод SwiftUI по ключу не работает:
оборачивать вручную. Слова, что приходят с сервера как протокол (ключ папки, имя фоновой задачи, префикс статуса),
не переводятся: для показа есть словари (`FOLDER_RU`, `BackgroundJob.rawName`, `OPTION_RU`), сравнение — по исходной
русской строке.

## Скорость и надёжность

- Модель не наблюдать из мелких деталей; обзор публиковать только при изменении; опрошенные данные не перезаписывать
  одинаковыми (`JSON.isSame`). Список задач опрашивается часто только пока задачи идут.
- Длинные списки — ленивые строки одной высоты (`EventList`); `Table` — только для длинных журналов (расходы).
- Чтение диска и разбор JSON — не на главном потоке; поздний ответ сервера не рисуется в чужой раздел.
- Несохранённые правки: экран сообщает `model.setUnsaved(ключ, Bool)`, переход, который их потеряет, спрашивает сам.
- Узкое окно: `@Environment(\.narrowWindow)`; в шапке поиск — значок, фильтры — `Segments(collapses: true)`.
- Запуск: заставка `PlaceholderView` не меньше `Style.Motion.intro`, потом окно и блоки въезжают каскадом.
  «Уменьшить движение» в системе выключает всю анимацию.
